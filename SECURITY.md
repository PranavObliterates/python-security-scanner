# Security Policy

## Supported Versions

PySecure actively supports the latest release for security updates and bug fixes:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

As a security scanner, we take the security of PySecure and its dependencies very seriously.

If you believe you have found a security vulnerability in PySecure (including AST analysis bypasses, unexpected remote execution vectors, or unsafe deserialization risks):

1. **Do not open a public GitHub issue.**
2. Send an email to the repository maintainer or submit a Private Vulnerability Report via GitHub's **Security Advisories** tab.
3. Include:
   - Description of the vulnerability.
   - Proof of Concept (PoC) code or target application snippet.
   - Any proposed remediation or patches.

You will receive an initial response within 48 hours, followed by updates as the issue is investigated and patched.
